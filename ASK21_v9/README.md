# Alexander Schleicher - Kaiser ASK21 for FlightGear
The ASK21 is a tandem-seater glass-fibre glider constructed by Roland Kaiser and first flown in the later 1970s.<br/>
It is still produced by the glider manufacturer "Alexander Schleicher Flugzeugbau", meanwhile as the -B variant with mild improvements.<br/>
As it has very good-natured flight and stall characteristics, it is often used in flying schools and for aerobatic training.

## Developing Liveries
New Liveries should be developed in vector graphics to allow for easier changes in the future and keep the repository size small.<br/>
You can find a paintkit and all current liveries at src/ask21.svg.

## Authors and Development
Heiko Schulz (HHS) and Detlef Faber started this model originally in 2006, based on the Bocian by AJ MacLeod.
<br/>
It received a major update in 2016 by Thomas Polzer, Viktor Radnai, Bea Wolf and Gilberto Agostinho, using parts from the ASK13 by Patrice Poly.
Since then, it is under active development, previously at github.com/viktorradnai/flightgear-ask21.git and from 03/2023 directly in FGAddon.
<br/>
Thanks to Herbert Wagner for various fixes and improvements, including a wind compass (meanwhile superseded by the "Anemoi"), MP fixes and a more realistic stall simulation!<br/>
Passenger view based on dual control code by Anders Gidenstam.

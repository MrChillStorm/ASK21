# LXNAV V8 vario indicator (front panel)

Replaces the ILEC SC7 of the front panel. In the glider it sits in the centre, where the separate G-meter was; in the
motorglider it sits at the bottom right. Based on the LXNAV V8 (57 mm) as described in the
LX90xx/LX80xx user manual (7.1.12.4) and the V8/V80 installation manual. The unit is shown standalone, as an
indicator; it gets its data from the flight model and its power from the battery switch (160 mA, as in the manual).
The ILEC script (`ilec-sc7.nas`) is still loaded: it only provides the `ilec-sc7/volume` property used by the S / s keys.

## Controls
* Middle button: next page (numeric, horizon, wind, FLARM radar, thermal assistant, G-meter). **Long press: setup menu.** On the G-meter page the top button resets the maximum and minimum (this page replaces the separate G-meter of the front panel).
* Top / bottom button: MacCready on the numeric page, zoom on the FLARM page, selection in the menus.
* Setup menu: top / bottom = move, short middle = open / change / confirm, long middle = back.
  In edit mode (value highlighted in orange) the top button raises and the bottom button lowers the value.
* Click the screen, or *ASK21 > LXNAV V8 close-up*, for a window with the screen.
* All settings are kept in `/instrumentation/lxv8/settings` and saved with the aircraft data.

## Behaviour
* Vario, netto, relative, average, thermal detection, MacCready speed to fly and the audio modes are ported from the
  FG9070 trainer (`js/flight/*.js`, `js/audio/vario-audio.js`). The polar is the ASK 21 flight manual's (fitted at
  470 and 570 kg, 0.02 m/s rms), scaled with the glider's actual mass, the load factor and the air density, so netto
  reads zero in still air at any speed, loading and height. Total energy uses the true airspeed, like a TE probe.
* Audio: `lxv8-tone.wav` (500 Hz triangle) is pitched and gated from Nasal (`/instrumentation/lxv8/audio/*`,
  `Sounds/ask21-sound.xml`). Speed-to-fly audio is muted below 72 km/h and behind the tug.
* Voice: on macOS run `python3 tools/lxv8-speak.py` while FlightGear runs with `--telnet=5401`. The instrument then sends the
  text of a message ("Thermal average 2.1", "Traffic 2 o'clock, high, 400 meters") to the helper, which speaks it with the
  `say` command in the system voice, like FG9070 does in the browser. Without the helper (or on other systems) the
  instrument plays prerecorded clips (`Sounds/lxv8-voice/`, made with `src/make_voice.py`; every clip is a one-shot sound in
  `Sounds/ask21-sound.xml`, started through `/instrumentation/lxv8/voice/clip`) one after the other.
* FLARM list: AI and multiplayer aircraft whose model name is a known glider (the list of FG9070), moving faster than 15 kt.

## Screws
All instruments with screws use the style of the Winter ASI: small dark Phillips heads (`Models/Interior/Panel/src/screwlib.py`).
The V8 builds them into its mesh; the 57 mm instruments (G-meter, radio, compasses, transponder) share
`Instruments/GMeter/57mm_screws.ac` (`src/make_57mm_screws.py`).

## Files
* `lxv8.xml`, `lxv8.ac`, textures: the housing (generated by `src/make_model.py`, dimensions from the manual).
* `lxv8-core.nas`: data, audio, voice. `lxv8.nas`: Canvas screen, buttons, menus.
* `src/make_tone.py`: the tone sample.

## Not implemented
HAWK, flaps and speed tape, G-meter bar / diamond, custom colours, files and password menus, the main unit (LX90xx) itself.

## Development
`/instrumentation/lxv8/dev/reload = 1` reloads both .nas files from `/instrumentation/lxv8/dev/path` (default: the aircraft
folder) and restarts the instrument. FlightGear only lets Nasal read its own folders, so for iterating from a working
copy put the two files below `$FG_HOME`.
